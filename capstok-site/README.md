# Capstok Website

Een moderne, statische landingspagina voor www.capstok.nl

## Bestanden

- `index.html` - De hoofdpagina
- `styles.css` - Aangepaste CSS stijlen
- `script.js` - JavaScript functionaliteit

## Functies

- Responsive design (werkt op desktop, tablet en mobiel)
- Moderne donkere industriële look
- Vloeiende scroll-animaties
- Mobiel menu

## 🔐 Admin Bewerkingsmodus

Om de website te bewerken zonder code aan te passen:

1. Open de website in je browser
2. Typ op je toetsenbord: **1990**
3. De bewerkingsmodus wordt geactiveerd
4. Klik op tekst om deze te bewerken
5. Klik op "Wijzigingen Opslaan (Kopieer HTML)" om de bijgewerkte HTML te kopiëren
6. Plak de gekopieerde code in je `index.html` bestand op GitHub

## Deployment op GitHub Pages

1. Maak een nieuwe GitHub repository aan
2. Upload alle bestanden naar de repository
3. Ga naar Settings > Pages
4. Selecteer "Deploy from a branch"
5. Kies de `main` branch en `/root` folder
6. Klik op Save
7. Je website is nu live op: `https://[gebruikersnaam].github.io/[repository-naam]/`

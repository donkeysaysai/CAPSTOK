# Capstok Landing Page - PRD

## Oorspronkelijke Probleemstelling
Maak een moderne, responsive landingspagina voor www.capstok.nl met:
- Statische website voor GitHub Pages hosting
- Verborgen admin bewerkingsmodus (code: 1990)
- Contenteditable tekstvelden in admin modus
- "Kopieer HTML" functionaliteit voor wijzigingen

## User Persona
- **Primair**: Website eigenaar van Capstok die de website zelf wil kunnen bewerken
- **Secundair**: Potentiële klanten die geïnteresseerd zijn in de CAPSTOK helmhouder

## Core Requirements (Statisch)
1. ✅ Responsive design (desktop, tablet, mobiel)
2. ✅ Hero sectie met "Welcome to a safer future" boodschap
3. ✅ Waarom CAPSTOK sectie (Veiligheid, Orde, Vakmanschap)
4. ✅ Producten sectie (CAPSTOK Wit & Zwart - €16,99)
5. ✅ Over Ons sectie
6. ✅ Contact sectie (info@capstok.nl, +31 6 81140979)
7. ✅ Admin modus activatie via code "1990"
8. ✅ Contenteditable tekstvelden in admin modus
9. ✅ HTML kopiëren naar klembord functionaliteit
